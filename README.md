# 川越さんぽ（Kawagoe Quiet Walk）

混んでいる一番街を避けて、空いている川越へ。空いている場所・時間・お店がわかる周遊ガイドの試作です（非公式）。

https://satou-aaaaa.github.io/kawagoe-sanpo/

- **いま**：曜日と時間から、一番街の混み具合の目安と、いま行くなら空いている場所（近い順・方角・歩く分）。
- **何時が空く？**：場所ごとに、8〜21時の混み具合の目安。
- **コース**：喜多院・仙波／お城と神社／朝の一番街／夜の川越。
- **お店**：お店がボタン1つで「いま空いてます」を出す仕組みの見本（お店は作り話）。
- 日本語・English・中文・한국어。一度開いて端末に保存が済めば、電波がなくても使えます（保存できなかったときは、次にネットにつながったとき保存し直します）。外へは何も送りません。

混み具合は、観光庁の資料にある地区ごとの人出の差（一番街周辺 約271万人、喜多院 約26万人など）と、ふつうの時間帯の混み方から作った目安です。いまの人の数を測ったものではありません。

出典：観光庁「川越市におけるオーバーツーリズム対策事業」（令和6年度）・「埼玉県川越市」（令和7年度）、川越市「令和6年 観光アンケート調査報告書」、国土地理院「住所検索」。
